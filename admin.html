Format attendu

Le JSON est un tableau d'objets. Seul id est obligatoire ; c'est lui qui identifie le client d'un import à l'autre.

[ { "id": "123456789", "nom": "EARL EXEMPLE", "adr": "12 RUE DES CHAMPS 80200 EXEMPLEVILLE", "naf": "Culture de céréales…", "tel": ["0322000000"], "commercial": "nom.prenom", "nb_machines": 2, "annee_achat": 2027, "machines": [ { "marque":"MARQUE", "modele":"MODELE", "categorie":"Tracteur", "etat":"NEUF", "plaque":"AA-123-BB", "annee":2026 } ] } ]

Le CSV (séparateur ; ou ,) met à jour les clients et leur attribution, mais pas le parc matériel. En-têtes reconnus : id, nom, adr, naf, tel, commercial, nb_machines, annee_achat. Plusieurs téléphones se séparent par un espace.

Le champ commercial doit contenir l'identifiant du vendeur (de la forme nom.prenom), exactement comme dans la table vendeurs. Toute autre valeur — Non attribué, hors.secteur, une faute de frappe — rend le client visible de vous seul.
